# What the Railway service installs. Three direct dependencies; the rest are
# theirs. Every version is pinned, including the indirect ones, so a deploy in
# six months installs the same bytes as the deploy that was tested - a web
# service that quietly picks up a new minor version of its framework is a
# service that breaks on a Tuesday for no reason anybody can see.
#
# Checked by installing this file into an empty Python 3.12 environment:
# 16 packages, 30 MB on disk (pip, not the container image).
#
# Note what is NOT here: nothing for cryptography (server/signing.py verifies
# Ed25519 with the standard library alone), nothing for a database, nothing for
# sessions, nothing for metrics. This service stores nothing about anybody.
